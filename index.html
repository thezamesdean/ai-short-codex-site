PERSONAL CHANNEL OPERATIONS

AI Short Codex

A local tool for the owner's Tiny Proof Lab and Object Unfolded YouTube channels. This site explains the tool and its data practices. It does not offer public registration or a third-party channel management service.

What the tool does

The tool uses the YouTube Data API to support channel-owner-authorized video uploads, scheduling, metadata updates, performance checks and viewer-comment replies. AI assistance helps prepare and review work. Editorial review and the owner's current publishing instructions govern each upload.

Access is requested through Google OAuth. Each connection is checked against the intended channel ID before it is stored. Google credentials are kept in a private directory on the owner's Mac, separate from this public website.

Channels

  • Object Unfolded

Connecting a channel does not authorize publication of every draft. A paused channel remains paused until the owner resumes it.

Privacy and support

Read the Privacy Policy for data access, storage, sharing and revocation details. The owner can request help through the existing operator conversation or the support contact shown on the Google authorization screen.
